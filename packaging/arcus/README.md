# Arcus Consumer Template (`packaging/arcus`)

This directory provides the canonical entry point for packaging and distributing UltraCreative's own subc modules via the Arcus gateway (the stock `ck-subc`, `ck` and `ck-subc-mcp` come from CortexKit's official installer).

## Structure

- `ck-uc-discussions.json`: Package descriptor for the discussions service (`ck-uc-discussions`).
- `bootstrap.sh`: Automated toolchain setup script.
- `toolchain/`: Symlink to the Arcus-managed `arcus-publisher` installation (generated by `bootstrap.sh`, gitignored).
- `.gitignore`: Ignores `toolchain/`.

## Setup

Run the bootstrap script from the repository root:

```sh
sh packaging/arcus/bootstrap.sh
```

This will:
1. Verify `arcus` CLI is installed and available on `PATH`.
2. Install or update the `arcus-publisher` package (`arcus install arcus-publisher`).
3. Symlink `packaging/arcus/toolchain` to the Arcus installation directory.
4. Symlink `.opencode/skills/arcus-publisher` to `packaging/arcus/toolchain/skill`.
5. Symlink the standard lifecycle scripts into `packaging/scripts/`.
6. Run `arcus manifest verify-toolchain` to validate the toolchain headers.

## Packaging & Publishing

To package all suite components under `dist/<sequence>/<package>/<version>/`:

```sh
bun run pack:arcus
# or: sh packaging/scripts/pack-all-arcus.sh
```

To publish and submit immutable release bundles to the Arcus gateway:

```sh
bun run publish:arcus
# or: sh packaging/scripts/publish-all-arcus.sh
```

To query the status and verification diagnostics of a release submission:

```sh
arcus publish status <submission-id>
```

## Submodule Prohibition

Projects distributing via Arcus must **NOT** add the `arcus` repository as a git submodule. Direct writes to the Arcus repository from consuming projects are strictly prohibited. All updates to the publisher tooling are managed through `arcus install arcus-publisher`.
